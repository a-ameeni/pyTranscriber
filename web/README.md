# pyTranscriber Web — نسخهٔ مرورگری

رابط فارسی برای رونویسی صوت و ویدئو و تولید فایل‌های TXT/SRT/VTT، در کنار برنامهٔ رومیزی مخزن.

## اجرا
وب‌اپلیکیشن را از پوشهٔ web با میزبانی ایستای HTTPS باز کنید. کتابخانه و مدل از اینترنت دریافت می‌شوند و پردازش گفتار روی دستگاه کاربر انجام می‌شود.

## دسترسی آنلاین بدون نصب

نشانی ثابت و آزمایش‌شدهٔ نسخهٔ وب (میزبان واسط، با احتمال نمایش صفحهٔ تأیید امنیتی):
https://raw.githack.com/a-ameeni/pyTranscriber/master/web/index.html

این نشانی به شاخهٔ اصلی مخزن متصل است، برخلاف پیوندهای وابسته به شناسهٔ یک ثبت تغییر خاص. برای انتشار نهایی بدون تأیید واسط، لازم است GitHub Pages یک‌بار در تنظیمات مخزن فعال شود.

## انتشار
گردش‌کار .github/workflows/web-pages.yml با تغییرات master پوشهٔ web را منتشر می‌کند. در Settings → Pages → Build and deployment → Source = GitHub Actions انتشار Pages را فعال کنید و در صورت لزوم از Actions گردش‌کار را دوباره اجرا کنید.

نشانی مورد انتظار پس از فعال شدن صفحات گیت‌هاب: https://a-ameeni.github.io/pyTranscriber/

## قابلیت‌ها
- افزودن چند فایل، صف پردازش، وضعیت و توقف، مشاهدهٔ خروجی هر فایل
- فارسی، انگلیسی، عربی، سایر زبان‌ها و تشخیص خودکار
- مدل‌های چندزبانهٔ Whisper tiny و base؛ پردازش گرافیکی در صورت پشتیبانی
- ویرایش بخش‌های زمان‌بندی‌شده، دانلود TXT/SRT/VTT و کپی متن
- بدون ارسال فایل‌های ورودی به سرور برنامه

## محدودیت‌ها
- این نسخه اجرای مستقیم پایتون/کیوت نیست؛ بازپیاده‌سازی مرورگری با Transformers.js و Whisper است.
- قالب صوت و ویدئو باید توسط مرورگر قابل رمزگشایی باشد. برخی MKV/WMA/FLAC/MP4 پشتیبانی نمی‌شوند.
- مدل اولیه ممکن است صدها مگابایت حجم داشته باشد؛ سرعت و دقت روی تلفن متغیر است.
- خروجی به‌صورت دائمی میان دستگاه‌ها همگام‌سازی نمی‌شود.
- پشتیبانی واقعی از دستگاه‌ها و مرورگرهای متفاوت نیاز به آزمون میدانی دارد.

## ساختار
web/index.html رابط؛ web/style.css ظاهر؛ web/app.js کنترل و صادرات؛ web/worker.js موتور Whisper.
